# What are the five layers of the Transformation Stack?

The transformation has five layers, each building on the one below. Organizations that attempt to skip layers — deploying AI tools without redesigning workflows, or redesigning workflows without developing capability — fail to capture the value and create significant risk.

| Layer | What it means | Key interventions |
| :--- | :--- | :--- |
| **L1: 2050 North Star (Ecosystem Role)** | Strategic positioning as orchestrator, realizer, or enabler within life-area ecosystems; building toward trust-infrastructure status | Ecosystem Strategy Map (Kawohl & Krechting), partnership portfolio design, interoperability commitments, open-standard contributions |
| **L2: Business Model** | Repricing value creation around outcomes, trust and ecosystem contribution rather than input hours or proprietary lock-in | Outcome-based pricing pilots, capability-product development, stewardship vector analysis, Common Good Balance Sheet |
| **L3: Capabilities** | Training, agency development, entrepreneurial mindset and decision-making capacity at every level of the organization | Character strengths profiling, self-efficacy workshops, Mindset Alchemy, AI literacy programs, leadership development grounded in self-authoring mindset |
| **L4: Workflows** | Redesign of tasks and processes around augmentation logic: which tasks go to AI, which stay with humans, which are redesigned as human–AI collaboration | AI Potential Maturity Analysis, human-in-the-loop protocol design, task taxonomy (Labor/Work/Action), workflow pilots |
| **L5: Tools** | Copilots, automation, assistants — deployed as augmentation instruments, not replacement systems | Tool selection based on capability-expansion criteria, bias audit, contestability design, human override protocols |
